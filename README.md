# Efficient Data Lookup Comparison Python

This example demonstrates the critical importance of Data Structures and Algorithms (DSA) by comparing two methods for searching data: a naive linear search and an efficient hash map (dictionary) lookup. It highlights how choosing the right data structure can significantly impact performance and scalability, a foundational concept for any software engineer.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
